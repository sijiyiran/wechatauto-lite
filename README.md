# wechatauto-lite

微信自动回复机器人的**自动更新源**。

这个仓库只放程序文件，不放运行时数据（config / 记忆 / 日志都不在这里）。

## 版本

- 当前版本：**v1.3**
- 类型：`portable`
- 文件数：32

## 自动更新

程序里的「设置 → 更新」会自动检查这个仓库的 Release。

更新特点：
- **只下载变化的文件**（按 sha256 对比，不会整个重下）
- **只删本地多出来的程序文件**
- **不碰** `config.json` / `state.json` / 记忆 / 日志 / 人格卡
- **国内加速**：默认走 jsDelivr CDN，失败自动回退其它镜像

## 手动更新

如果自动更新坏了，直接下 Release 里的 `manifest.json` 看文件清单，
按清单从仓库拉文件也行。
