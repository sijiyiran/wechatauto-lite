一个能在微信群里**像个人一样**接话的自动回复工具。

它不会对每条消息都抢着回 —— 而是先判断"这句话是不是在跟我说话、我能不能接、接了说什么"，再决定开不开口。

## 关于开发版下架

**开发版（全功能版）已从 GitHub 下架，仓库已转为私有。**

**下架原因：防止核心功能泄露。**

开发版包含完整的功能实现和内部逻辑。这些内容一旦公开：
- 会被直接复制、改个名字当成自己的软件发布
- 核心算法和策略会被别人白拿走
- 作者投入的开发时间失去保护

**所以开发版不再公开分发。** 现有稳定版已经覆盖绝大多数日常使用场景，功能足够。

> 如果你之前下载过开发版：它能继续用，但**不再有自动更新**（更新源已关闭）。
> 想继续获得更新，请换用本稳定版。

## 稳定版有什么

### 群里像人一样聊天
- 判断**要不要接话**：被 @ 时接、话题相关时接、闲聊时大多数时候闭嘴
- 有**人格和情绪**：会记仇、会撒娇、会累、有心情变化，不是复读机
- **拟人延迟**：不会秒回，像真人在打字
- 支持**群聊和私聊**

### 实用的自动化
- **收发红包 / 转账**：群里发红包自动领，转账自动收（超过设定金额会跳过）
- **拍一拍**：需要时拍一下群里的人
- **表情包**：说完话偶尔补一张图
- **看图**：有人发图片时能"看到"并据此回应

### 防打扰设计
- **夜间模式**：设定时间段内完全不回消息
- **冷却和频率限制**：不会刷屏
- **静默窗口**：群里吵起来时先等安静
- **置信度阈值**：没把握就不开口

### 安全和可控
- **只认你的指令**：可以设置只有指定微信号能触发的功能
- **模拟运行**：先看它会说什么，不真的发
- **可随时停用**：一个开关关掉

## 稳定版没有的功能

以下功能**仅在开发版提供**，稳定版已关闭：

- 朋友圈自动浏览、点赞、评论
- 自动处理好友申请
- 消息转述（把内容转发到别的应用）
- 主动搭话（自己找话题）

这些功能需要更复杂的界面操作，稳定性风险较高，因此没有放进稳定版。

## 安装

> 还没决定装不装？先看 [产品介绍页](http://5.189.142.51:11562/)。

1. 从 [Releases](../../releases) 下载最新的 `WeChatAutoReply-Lite-Setup-x.y.exe`
2. 双击安装（**不需要管理员权限**，装到当前用户目录）
3. 启动后打开「设置」，填写：
   - **API Key**（大模型服务的密钥）
   - **只认这个微信**（点「识别当前聊天」自动填）
   - **勾选要参与的群**
4. 保存，程序会自动开始工作

## 自动更新

程序里的「设置 → 更新」会自动检查新版本。

更新特点：
- **只下载变化的文件**（按 sha256 对比，不整个重下）
- **不碰你的数据**：`config.json`、记忆、日志、人格设置都不会被覆盖
- **国内加速**：走国内可达的 CDN，失败自动回退

## 常见问题

**Q：会不会封号？**

这是驱动你本机已登录的微信客户端，属于自动化操作，**存在违反微信平台规则的风险**。建议：
- 不要高频使用
- 不要用于营销、刷屏
- 自己承担使用风险

**Q：需要一直开着电脑吗？**

是。程序需要在后台运行，且微信必须保持登录。

**Q：API Key 存哪？**

保存在 **Windows 凭据管理器**（系统加密，只有你的账户能读），不会明文写在配置文件里。

**Q：我的聊天记录会被上传吗？**

不会。聊天记录只在本机处理，只有需要判断的那几条会发给大模型服务（用于生成回复）。
